# Wireframe

`wireframe.html` — mở thẳng bằng trình duyệt, không cần server.

Đây là bản wireframe đã dùng để chốt bố cục trước khi dựng. Giữ lại để sau này đổi giao diện
thì có cái so, và để thấy **vì sao** chọn bố cục hiện tại chứ không phải hai bố cục còn lại.

Thanh công cụ trên cùng đổi được: **Màn** (Landing / Đơn hàng) · **Phương án** (A B C + biến thể
D, E) · **Màu** (Xám / Màu) · **Khổ** (Desktop / Mobile) · **Trạng thái** (có dữ liệu / đang tải /
rỗng / lỗi). Mọi lựa chọn nằm trên URL nên gửi link là người khác mở ra đúng cái đang xem.

**Đã chọn: Landing A + Đơn hàng A.** Lý do và đánh đổi của từng phương án nằm ngay trong trang,
ở khung trên cùng.

Wireframe dựng bằng đúng token trong `frontend/src/index.css` và đúng class mà bản dựng dùng,
nên bật nút **Màu** lên là gần đúng bản thật.

Quy trình: skill `ui-ux` của [evondevKit](https://github.com/evondev/evondevKit), cài ở
`.claude/skills/ui-ux/`.
